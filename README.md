# CSES Problem Set Solutions

This repository contains my solutions to the problems from the [CSES Problem Set](https://cses.fi/problemset/). The goal is to practice competitive programming and improve problem-solving skills.

## What I Am Trying to Do

- Solve problems from the CSES Problem Set.
- Enhance my understanding of algorithms and data structures.
- Prepare for competitive programming contests.

## How to Run the Codes

1. Open the `.cpp` file for the problem you want to run.
2. Use the following shortcut to compile and run the file:
   ```
   ctrl + shift + B -> run the current cpp file.
   ```
3. Ensure you have a C++ compiler (e.g., g++) installed and configured in your environment.

## Where Am I Submitting Them?

All solutions are submitted to the [CSES Problem Set platform](https://cses.fi/problemset/) for validation and scoring.

## Additional Notes

- Each solution is written in C++.
- The repository is organized for easy navigation and reference.
